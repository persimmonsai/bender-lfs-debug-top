# HBM4 Simulation Model

This repository contains a SystemVerilog simulation model, Bus Functional Model (BFM), and testbench for the High Bandwidth Memory (HBM4) standard, focusing on the JESD270-4 specification.

## Features Implemented
- Basic Read/Write Burst operations
- Row Activation and Precharge mechanics
- Advanced Activation Timings (`tFAW`, `tRRD_L`, `tRRD_S`)
- Write-to-Read / Read-to-Write Turnarounds (`tWTR_L/S`, `tRTW`)
- Read-to-Precharge Timings (`tRTP`)
- Precharge All (`PREA`) and Per-Bank Refresh (`REFpb`)
- Command and Address Parity Checking (`AERR`)
- Mode Register Read/Write (`MRS`, `MRR`)
- Low-Power States (Power-Down, Self-Refresh) and Timings (`tPD`, `tXS`, `tCKSRE`)
- Data Error reporting (`DERR` pin) and Internal ECC Error injection
- IEEE 1500 Wrapper Serial Port (WSP) Test Interface

## Prerequisites
To run the simulation, you need a SystemVerilog simulator. The provided `Makefile` is configured for Cadence Xcelium (`xrun`). 

On environments using environment modules, ensure you load Xcelium before running:
```bash
source /etc/profile.d/modules.sh
module load cadence/xcelium
```

## Running the Simulation

All simulation tasks are executed from within the `sim/` directory.

```bash
cd sim
```

### 1. Run the Full Regression Suite
To run all test cases consecutively and ensure the model passes cleanly:
```bash
make regress
```

### 2. Run a Specific Test
To run an individual test case, pass the `TEST` argument to `make regress`. For example, to run the IEEE 1500 test:
```bash
make regress TEST=test_ieee1500
```

Available tests include:
- `test_basic_rw_bursts`
- `test_timing_ccd`
- `test_timing_rtp`
- `test_timing_wtr`
- `test_timing_faw_rrd`
- `test_prea_refpb`
- `test_mrs_config`
- `test_mrr`
- `test_parity_error`
- `test_derr_ecc`
- `test_low_power_states`
- `test_ieee1500`
- `test_random_traffic`
- `test_concurrent_traffic`
- `test_refresh_mechanics`

### 3. Clean Simulation Artifacts
To remove compiled databases, histories, and logs generated by Xcelium:
```bash
make clean
```
